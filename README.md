# 야츄

주사위 다섯 개, 흔들기 세 번. 휴대폰에서 바로 하는 야추(Yacht) 주사위 게임입니다.

**바로 하기: https://oojo-9.github.io/DICE-GAME/**

설치 없이 브라우저에서 열면 되고, 홈 화면에 추가하면 앱처럼 전체 화면으로 쓸 수 있습니다.

## 게임 모드

| 모드 | 설명 |
| --- | --- |
| 한 기기로 | 기기 하나를 돌려 가며 1~8명이 함께 합니다. |
| 온라인 | 방을 만들고 5자리 방 코드를 알려 주면 친구가 각자 기기로 들어옵니다. 상대가 굴리는 주사위도 실시간으로 보입니다. |
| AI랑 대결 | AI가 스스로 굴리고, 고정하고, 점수를 기록합니다. |

## 하는 법

1. 휴대폰을 흔들거나 굴리기 버튼을 길게 눌렀다 놓아 주사위를 굴립니다.
2. 남기고 싶은 주사위를 눌러 고정하고, 나머지를 다시 굴립니다. 한 차례에 세 번까지 굴릴 수 있습니다.
3. 점수판에서 칸 하나를 골라 기록합니다. 한 번 기록한 칸은 바꿀 수 없습니다.
4. 모두가 12칸을 다 채우면 끝나고, 합계가 가장 높은 사람이 이깁니다.

## 점수

| 칸 | 조건 | 점수 |
| --- | --- | --- |
| 에이스 ~ 헥사 | 해당 눈(1~6) | 그 눈의 합 |
| 보너스 | 위 6칸 합이 63점 이상 | +35 |
| 초이스 | 아무 조합 | 주사위 5개의 합 |
| 포커 | 같은 눈 4개 | 그 4개의 합 |
| 풀하우스 | 같은 눈 3개 + 2개 | 주사위 5개의 합 |
| 스몰스트레이트 | 연속된 눈 4개 | 15 |
| 라지스트레이트 | 연속된 눈 5개 | 30 |
| 야츄 | 같은 눈 5개 | 50 |

## 그 밖의 기능

- 쟁반 위를 실제로 굴러다니는 3D 주사위와 충돌 소리
- 쟁반 배경을 직접 찍은 사진으로 바꾸기 (사진은 기기 밖으로 나가지 않습니다)
- 하던 게임 저장, 온라인 방 재접속
- AI 대결·온라인 전적과 최고 점수를 기기에 기록
- 온라인에서 접속이 끊기거나 응답이 없는 사람의 차례 넘기기, 동의를 받아 중간에 나가기

## 직접 돌려 보기

빌드 과정이 없는 정적 페이지입니다. 저장소를 받아 아무 정적 서버로 띄우면 됩니다.

```bash
python -m http.server 8000
```

`index.html`을 파일로 바로 열어도 한 기기 모드와 AI 대결은 동작합니다.

온라인 모드는 Firebase(익명 로그인 + Realtime Database)를 씁니다.

## 이용 통계

이용자 수를 파악하려고 Google Analytics로 접속과 게임 시작 횟수(모드, 인원)를 집계합니다. 닉네임이나 점수 같은 게임 내용은 보내지 않습니다.
